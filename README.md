# Stellar Burgers — Конструктор космических бургеров

Одностраничное приложение (SPA) для заказа бургеров в футуристичном ресторане. Пользователь может собрать собственный бургер из ингредиентов, оформить заказ и отследить его статус в личном кабинете.

## Проблема и решение
**Проблема:** Создать интерактивный интерфейс для сборки бургера с сохранением состояния корзины и историей заказов, интегрированный с внешним API.

**Решение:** Приложение построено на React с использованием Redux Toolkit для управления глобальным состоянием. Реализована авторизация и защищенные маршруты для доступа к личному кабинету. Интеграционные тесты на Cypress и Jest гарантируют корректную работу ключевых сценариев.

## Ключевые возможности
- **Конструктор бургеров:** Перетаскивание ингредиентов (drag-and-drop), динамический подсчет стоимости.
- **Управление заказами:** Оформление заказа, просмотр истории заказов в личном кабинете.
- **Авторизация и безопасность:** Защищенные роуты, работа с JWT-токенами.
- **Интеграция с API:** Загрузка списка ингредиентов и отправка заказов на сервер.
- **Тестирование:** Написаны E2E-тесты (Cypress) и юнит-тесты (Jest) для проверки критических сценариев.

## Технологический стек
- **Frontend:** React, TypeScript, Redux Toolkit, React Router
- **Стилизация:** CSS Modules
- **Сборка:** Webpack
- **Тестирование:** Jest, Cypress
- **API:** REST

## Архитектура и моя роль
Проект выполнен в рамках учебного спринта Яндекс.Практикума. Моя роль включала **полную реализацию клиентской части**:
- Настройка роутинга и создание защищенных маршрутов.
- Разработка слайсов и настройка асинхронных запросов к API через `createAsyncThunk`.
- Реализация логики drag-and-drop для конструктора бургеров.
- Покрытие ключевых пользовательских сценариев интеграционными тестами на Cypress.
